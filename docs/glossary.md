# MoonSmith 术语索引

项目概念由所属提案定义，本页只提供名称与定义位置。定义规则见
[FP-0000](../fps/FP-0000-governance.md#术语定义与引用)，机器可读的定义归属见
[fps-index.json](../fps-index.json)中各提案的 `defines`。
这里的概念不要求对应同名类型、包或算法；当前 API 和实现边界见各模块 README。
