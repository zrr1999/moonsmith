## 三例未完成比较

三例均通过完整结构检查；native debug 和 wasm-gc debug 构建、执行成功且输出一致，native release 编译退出码为
255。原始诊断及生成 C 文件显示，C 编译阶段引用未声明的 `constr` 临时标识符，分别为 `_M0L6constrS87`、
`_M0L6constrS88` 和 `_M0L6constrS8`。

| 种子 | 两个成功配置的输出 | 后续分析 |
| --- | --- | --- |
| 1272 | `-7`，末尾一个 LF | [结构化与人工缩减](native-release-analysis.md#种子-1272-的-402-字节结果) |
| 3745 | `2147483646`，末尾一个 LF | [结构化与人工缩减](native-release-analysis.md#种子-3745-的-317-字节结果) |
| 6968 | `true`，末尾一个 LF | [结构化与人工缩减](native-release-analysis.md#种子-6968-的-422-字节结果) |

三例的独立源码重放再次得到相同配置、阶段、退出码和诊断模式。这支持随机生成路径发现可重复的工具链异常；这些证据
未确定三例是否同一根因，不将其称为三个独立缺陷，也未宣称与历史问题相同或已获上游确认。

被测构建的差分判定要求正常输出可比较，因此三例结论为 `Incomplete`，CLI 返回 3。原始构建失败的状态与诊断单独保留，
不会冒充输出分歧。该构建仅对正常输出分歧自动归约，三例未启动归约；现行产品行为见
[CLI 模块说明](../modules/cli/README.md#差分执行与存证)。

可在相同代码、生成器和工具链条件下重新生成第一例，另两例替换起始种子：

## 规模任务复现

在被测源码提交下按[安装说明](../README.md#安装)安装 CLI。
[acceptance.toml](../acceptance.toml)固定生成器、预算和五配置。分别执行：

```shell
moonsmith run --config acceptance.toml \
  --set 'name="acceptance-five"' \
  --set 'output.directory="runs/acceptance-v2/five"'

moonsmith run --config acceptance.toml \
  --set 'name="acceptance-basic"' \
  --set seed_start=1000 --set sample_count=9000 \
  --set 'execution.configurations=["native-debug","native-release","wasm-gc-debug"]' \
  --set 'output.directory="runs/acceptance-v2/basic"'
```

相同生成器版本、种子及预算应产生相同源码；目录和随机材料 ID 会变化，墙钟耗时不要求一致。安装后的 release 程序与
预试运行的 debug 程序在种子 0–99 上产生的源码及生成元数据逐一相同。原始逐例执行材料按[发行附件约定](releasing.md#产物与材料)保存在独立历史证据包中，
包含原始源码、配置、观察和汇总，排除构建缓存。原记录保持不变，重新运行产生新的执行证据。

任务结束后另对种子 0、999、1000、9999 和三例异常进行源码重放，四例正常输入继续一致，
三例异常继续未完成比较。案例、源码、原始尝试、样本、生效配置及任务汇总的校验和均未改变。
重放产生新的执行证据，不替换原始结果，也不计入 10,000 个计划样本。

## 结论边界

本次规模实验统计固定生成器、语义子集、预算和工具链下的内部检查通过率、基线编译接受率及比较完成率，
未测量动态执行覆盖率或具体优化的触发情况。三例构建异常的后续缩减、阶段对照及 189 字节同模式小复现见
[构建异常分析](native-release-analysis.md)。

被测实验版本中的完整程序求值器已从当前交付范围撤出，不计入十月验收；上述规模任务始终只按差分结果判定。
