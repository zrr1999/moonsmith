核对版本 2 汇总及原例校验和；后续继续运行全仓构建、行为测试与归约演示。
生成材料随 `execution-evidence` artifact 保留七天，具体运行结果以对应提交的 CI 为准。

或预编译发行包。本次单样本安装验收不计作[规模实验](project-proposal.md#预期验收产物)。
