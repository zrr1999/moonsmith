# 五配置执行矩阵验证

本报告验证同一生成程序在四后端、五个编译配置中的构建、结果比较与源码重放。
2026-10-21 的验证覆盖 100 个固定种子，全部配置均取得有效结果且输出一致。
本报告的样本范围独立于[项目申报书](project-proposal.md#预期验收产物)要求的规模实验。

## 方法与判定标准

在被测源码版本下准备[开发环境](../CONTRIBUTING.md#开发准备)，通过 CLI 源码入口执行任务：

```shell
moon run modules/cli/src/cmd/moonsmith --target native --deny-warn -- \
  run --config acceptance.toml --set sample_count=100 --set seed_start=0 \
  --set 'name="five-config-pilot"' --set 'output.directory="runs/five-config-pilot"'
```

任务读取该版本的 [acceptance.toml](../acceptance.toml)，使用表中的生成预算与超时。
每份输入先通过内部完整程序检查，再按既定顺序执行五配置。判定标准为：

- 每个配置的构建和执行均正常退出，输出满足该程序的 Int 或 Bool 观察协议。
- 五个规范结果一致；构建失败、超时、无效输出或缺失观察不计作一致。
- 保存案例包含源码、构建描述符、配置与原始观察，外部运行时版本探测完成。
- 对保存案例重放时取得新的执行证据，原例和原任务汇总保持不变。

观察协议与执行行为分别由 [MoonBit 模块](../modules/moonbit/README.md)和
[CLI 模块](../modules/cli/README.md#差分执行与存证)定义。

## 结论与适用范围

本次固定输入范围验证了五配置执行、正常结果比较、运行时存证与源码重放路径。
没有观察到输出分歧或未完成比较，也没有启动归约；不能据此推导编译器正确性、
随机发现缺陷的能力或真实缺陷归约效果。

这 100 个样本不计入申报书要求的 10,000 个样本及其中 1,000 例五配置实验。
原始逐样本记录未随源码发布；本文给出固定版本、输入条件、复现方法和汇总结果，
不提供原始数据下载。独立复测应保留新的生效配置、逐样本观察和任务汇总。
