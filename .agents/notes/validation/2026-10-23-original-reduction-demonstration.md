# 归约与重放演示

2026-10-21 使用真实 MoonBit 工具链完成一次受控故障注入的归约与重放。
注入只改变保存的比较输入，原始 stdout 单独保留；这份证据验证 MoonSmith 的检测与归约流程，
不属于真实编译器缺陷复现。

## 入口与条件

```shell
moon run modules/cli/src/examples/reduction --target native --deny-warn
```

[演示程序](../modules/cli/src/examples/reduction/main.mbt)调用现有库入口，对显式种子 7
使用默认生成预算和 16 个候选的预算。初始源码对应[固定归约输入](../cases/moonbit/reduce-root-call/main.mbt)，
使用 `template-rules-v1`、128 节点、深度 6、256 次构造尝试。

宿主为 Darwin 27.0.0 arm64，Moon 和 moonrun 为 0.1.20260920（`914d7da`），
编译器与 core 为 `0.10.14+7d59c7ec9`。执行 native-debug、native-release、wasm-gc-debug，
每次编译与运行超时分别为 30000、2000 毫秒。

注入将 native-release 的规范结果改成另一个同类型值，形成它与 native-debug 的输出分歧。
会话固定这个配置对；每个候选、独立确认及重放都各自重新编译运行，并取得本次注入证据。
其他配置对的差异、编译拒绝或超时不能替代目标。
